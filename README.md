# Candidate Project

## 📌 Overview

This project is a Java-based application to manage candidate details using basic concepts like classes, DAO (Data Access Object), exception handling, and database utility.

---

## 🗂️ Project Structure

* `CandidateBean.java` → Model class (stores candidate data)
* `CandidateDAO.java` → Handles database operations
* `CandidateMain.java` → Main class to run the program
* `DBUtil.java` → Database connection utility
* `WrongDataException.java` → Custom exception handling
* `Candidate.zip` → Additional resources (if any)

---

## ⚙️ Features

* Add candidate details
* View candidate information
* Validate input data
* Handle errors using custom exceptions

---

## 🛠️ Technologies Used

* Java
* JDBC (for database connection)
* OOP concepts

---

## ▶️ How to Run

1. Compile all Java files:

   ```bash
   javac *.java
   ```

2. Run the main class:

   ```bash
   java CandidateMain
   ```

---

## ⚠️ Notes

* Ensure database connection is properly configured in `DBUtil.java`
* Handle exceptions properly while entering input data
